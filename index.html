Toubib

Une plateforme de prise de rendez-vous médicaux en ligne qui met en relation patients et médecins. Le patient trouve un praticien et réserve un créneau en quelques clics ; le médecin gère ses cabinets, son agenda et ses patients.

Les trois applications

Le projet est découpé en trois applications indépendantes, chacune dans son propre dépôt et déployable séparément avec Docker.

Stack technique

Chaque application s'exécute dans son propre conteneur Docker et est servie par Nginx.

ApplicationRôleTechnologies
ToubibAPIAPI REST, logique métier et accès aux donnéesPHP 8.4, Symfony 8, Doctrine ORM 3, MySQL 8, Redis 7, LexikJWT, Nelmio CORS, Nginx
ToubibApplication web patientReact 19, Vite 7, React Router 7, Tailwind CSS 4, Nginx
ToubibBOApplication web médecin et administrateurReact 19, Vite 7, React Router 7, Tailwind CSS 4, FullCalendar, TanStack Table, Nginx

Installation requirement

  • Docker
  • Make (GnuWin32.make)
  • les trois repositories

Architecture

Les deux interfaces n'embarquent aucune logique métier : elles affichent les données et transmettent les actions de l'utilisateur à l'API, qui fait seule foi.

Interfaces ReactApplications monopages, échanges en JSON, cookies HttpOnly.
API SymfonyRoutes REST sous /api/, DTO validés, contrôle des droits.
StockageMySQL pour les données, Redis pour les tâches asynchrones, serveur de fichiers dédié.
